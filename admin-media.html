유튜브 주소를 붙여넣으면 영상 번호를 자동으로 찾아냅니다.

검색에 걸리는 부분입니다. 떡 이름이나 지역명을 넣으면 좋습니다.

3 홈페이지에 올리기

아래 버튼을 누르면 media.json 파일이 내려받아집니다. 그 파일을 GitHub 저장소에 올리면 끝입니다.

  1. 저장소 열기 ↗ 후 media.json 파일을 클릭합니다.
  2. 오른쪽 위 연필(✏️) 아이콘을 누릅니다.
  3. 내용을 전부 지우고, 위에서 복사한 내용을 붙여넣습니다.
  4. 아래 Commit changes 를 누릅니다.
  5. 1~2분 뒤 홈페이지에 반영됩니다.
파일을 끌어다 놓는 방법도 있습니다. 저장소 화면에서 Add file → Upload files 를 누르고 내려받은 media.json 을 끌어다 놓으면 같은 결과가 됩니다.
