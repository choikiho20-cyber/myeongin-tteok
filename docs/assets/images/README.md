# 이미지 · 영상 넣는 곳

이 폴더에 아래 이름 그대로 파일을 넣으면 **코드 수정 없이** 홈페이지에 바로 반영됩니다.
파일이 없는 동안에는 슬라이드가 색상 배경 + "준비 중" 표시로 대체됩니다.

| `banner-02.mp4` | 명인이 떡 빚는 손 | 영상 | ✅ 등록 완료 (1920×960, 6.17초, 1.8MB) |

### 촬영 순서와 이유

1. ~~**승검초단자**~~ ✅ 완료 — 좌측이 비어 있는 구도라 문구가 왼쪽에 얹힙니다. 이후 사진도 **한쪽을 비워두고** 찍으면 문구 자리가 생깁니다.
2. ~~**명인의 손**~~ ✅ 완료 — 2:1 · 6.17초. 슬라이드가 6.0초에 넘어가므로 반복 이음새는 보이지 않습니다.
3. **선물세트** — 택배 구매 전환. 박스 열린/닫힌 상태 둘 다, 정면 또는 45도.
4. **떡카페 체험** — 방문 유도. 체험 장면(촬영 동의 필수) 또는 인절미라떼 든 손 + 카페 내부.
5. **매장 외관** — 장소 각인. 간판이 잘 보이게, 맑은 날 오전~낮, 주차장이 보이면 좋음.

### 영상 주의사항

- 영상은 **2번·4번만** 권장합니다. 5개 모두 영상이면 모바일 데이터 소모와 로딩 지연으로 이탈률이 올라갑니다.
- **화면 비율은 2:1** — 목록에 있는 비율 중 PC·모바일 양쪽에서 가장 덜 잘립니다.
- **길이 6초**로 맞춰 주세요. 슬라이드가 그 슬라이드에 6초 머물도록 설정되어 있습니다
  (`index.html`의 `data-duration="6000"`). 길이를 바꾸면 이 값도 같이 바꿔야 합니다.
- **첫 프레임과 마지막 프레임을 비슷하게** — 반복 재생되므로 손 위치가 다르면 6초마다 화면이 튑니다.
- 파일당 **5MB 이하**로 압축해 주세요.
- 소리 없이 자동 재생됩니다. (브라우저 정책상 음소거 필수)
- `.mp4` 옆에 같은 이름의 `.jpg`를 함께 넣으면 영상 로딩 전에 그 사진이 먼저 보입니다.

### 안전 구역 (중요)

화면 폭에 따라 PC는 위아래가, 모바일은 좌우가 잘립니다.
**손과 떡은 화면 정중앙(가로 55% 안)에** 두고 가장자리에는 배경만 오게 촬영하세요.
자막·로고는 넣지 마세요 — 가장자리는 잘리고 중앙은 문구와 겹칩니다.
