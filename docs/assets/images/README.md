# 이미지 · 영상 넣는 곳

이 폴더에 아래 이름 그대로 파일을 넣으면 **코드 수정 없이** 홈페이지에 바로 반영됩니다.
파일이 없는 동안에는 슬라이드가 색상 배경 + "준비 중" 표시로 대체됩니다.

## 히어로 배너 (5장)

| 파일명 | 내용 | 형식 | 권장 크기 |
|---|---|---|---|
| `banner-01.jpg` | 승검초단자 클로즈업 | 사진 | 1440×480px |
| `banner-02.mp4` | 명인이 떡 빚는 손 | 영상 5~8초 | 1440×480px |
| `banner-02.jpg` | 위 영상의 대표컷 | 사진 | 1440×480px |
| `banner-03.jpg` | 선물세트 포장컷 | 사진 | 1440×480px |
| `banner-04.mp4` | 떡카페 체험 장면 | 영상 5~8초 | 1440×480px |
| `banner-04.jpg` | 위 영상의 대표컷 | 사진 | 1440×480px |
| `banner-05.jpg` | 매장 외관 + 제천 풍경 | 사진 | 1440×480px |

### 촬영 순서와 이유

1. **승검초단자** — 첫 3초에 "먹고 싶다"를 만드는 자리. 나무접시·한지 위에 3~5개, 잣가루가 보이도록 45도, 자연광.
2. **명인의 손** — "아무나 못 만든다"는 신뢰. 얼굴보다 손+떡 위주, 빚거나 잣가루 묻히는 동작, 가로 촬영 고정.
3. **선물세트** — 택배 구매 전환. 박스 열린/닫힌 상태 둘 다, 정면 또는 45도.
4. **떡카페 체험** — 방문 유도. 체험 장면(촬영 동의 필수) 또는 인절미라떼 든 손 + 카페 내부.
5. **매장 외관** — 장소 각인. 간판이 잘 보이게, 맑은 날 오전~낮, 주차장이 보이면 좋음.

### 영상 주의사항

- 영상은 **2번·4번만** 권장합니다. 5개 모두 영상이면 모바일 데이터 소모와 로딩 지연으로 이탈률이 올라갑니다.
- 파일당 **5MB 이하**로 압축해 주세요.
- 소리 없이 자동 재생됩니다. (브라우저 정책상 음소거 필수)
- `.mp4` 옆에 같은 이름의 `.jpg`를 함께 넣으면 영상 로딩 전에 그 사진이 먼저 보입니다.
