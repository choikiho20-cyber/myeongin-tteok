# 이연순 명인떡 브랜드 홈페이지 제작 브리핑

## 1. 프로젝트 개요

소통마케팅센터에서 이연순 명인떡에 납품하는 브랜드 홈페이지.
레퍼런스는 https://m.changeok.co.kr/ (창억떡) 느낌이되,
결제 시스템은 직접 구축하지 않고 네이버 스마트스토어로 연결하는 구조.

### 핵심 아키텍처
- 브랜드 홈페이지 (상품 카탈로그 + 브랜드 스토리 + 방문 안내)
- "구매하기" 버튼 → 네이버 스마트스토어 해당 상품 페이지로 이동
- 장바구니, 회원가입, 결제 시스템 직접 구현 안 함
- AI 검색(AEO/GEO) 최적화: 구조화된 메타데이터, FAQ, JSON-LD

### 기존 제작 레퍼런스 (내가 만든 것)
- donggang21c.com: AI 영상 슬라이더, 패키지 비교 탭, 네이버/카카오/구글 지도 연동, SEO 구조화 데이터, 고정 CTA 바
- geulhaejum.kr: SaaS 서비스, OAuth 로그인, 구독 결제, 대시보드

## 3. 브랜드 스토리 핵심 소재

### 수상 이력
- 2006년 전국떡경연대회 금상
- 2007년 서울국제요리경연대회 대상
- 2007년 한국음식대전 대상
- 대한민국 식품명인 제52호 지정

### 브랜드 키워드
- 3대째 이어오는 전통 가업
- 100% 국내산 원재료 (원산지 표기 철저)
- 제천 한방 특산물 활용 (당귀, 황기 등)
- 전통 제조 방식 고수
- 한국관광공사 여행가는달 선정 체험처
- 박은영 셰프 협업 이력

### 대표 상품: 승검초단자
- 당귀잎(angelica leaves) + 찹쌀 + 잣가루(pine nut powder)
- ⚠️ 쑥(mugwort) 아님! 당귀잎이 맞음. 콩가루 아님! 잣가루가 맞음.

## 5. 페이지 구성 (기획)

### 메인페이지
- 히어로 섹션: 명인떡 대표 이미지 + "대한민국 식품명인 제52호" 뱃지
- 브랜드 소개 요약 (3대 전통, 국내산 원재료)
- 대표 상품 쇼케이스 (각 상품 카드 → 스마트스토어 링크)
- 떡카페 소개 섹션
- 체험 프로그램 안내
- 오시는 길 (지도 임베드)
- 고정 하단 CTA 바 (전화걸기 + 스마트스토어 바로가기)

### 브랜드 스토리 페이지
- 이연순 명인 소개 + 수상 이력
- 3대 가업 히스토리
- 제조 과정 (원재료 → 완성)
- 원산지 표기 철학

### 상품 페이지
- 창억떡처럼 카테고리별 상품 그리드
- 각 상품 카드: 사진 + 이름 + 가격 + "구매하기" 버튼
- "구매하기" 클릭 → 네이버 스마트스토어 해당 상품으로 이동
- 선물세트 별도 섹션

### 떡카페 페이지
- 카페 분위기 사진
- 음료 메뉴
- 체험 프로그램 안내 (승검초단자 만들기 등)

### 오시는 길
- 네이버/카카오/구글 지도 임베드
- 주소, 영업시간, 주차 안내
