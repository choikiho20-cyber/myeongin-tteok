파일이 없는 동안에는 슬라이드가 색상 배경 + "준비 중" 표시로 대체됩니다.

### 촬영 순서와 이유

1. ~~**승검초단자**~~ ✅ 완료 — 좌측이 비어 있는 구도라 문구가 왼쪽에 얹힙니다. 이후 사진도 **한쪽을 비워두고** 찍으면 문구 자리가 생깁니다.
2. ~~**명인의 손**~~ ✅ 완료 — 원본에 자막이 새겨져 있어 상하단을 잘라내고 4.6초로 트림했습니다. 슬라이드는 4.4초에 넘어갑니다.
3. ~~**선물세트**~~ ✅ 완료 — 3:1. 버튼이 스마트스토어로 바로 연결됩니다.
4. ~~**전통음식체험관**~~ ✅ 완료 — 간판이 온전히 보이도록 3:1로 크롭했습니다.
5. ~~**매장 외관**~~ ✅ 완료 — 본관과 떡카페가 한 장에 담겨 떡카페 사진(`cafe-01.jpg`)으로도 잘라 썼습니다.

**배너 5장 모두 완료.** 제작용 촬영 가이드 패널은 삭제했습니다.

### 영상 주의사항

- 영상은 **2번·4번만** 권장합니다. 5개 모두 영상이면 모바일 데이터 소모와 로딩 지연으로 이탈률이 올라갑니다.
- **화면 비율은 2:1** — 목록에 있는 비율 중 PC·모바일 양쪽에서 가장 덜 잘립니다.
- **길이 6초 내외**로 맞춰 주세요. `index.html`의 `data-duration` 을 영상 길이보다
  약간 짧게 두면 반복 이음새가 보이지 않습니다. (현재 영상 4.6초 / 노출 4400ms)
- **자막·로고를 영상에 넣지 마세요.** 새겨진 자막은 지울 수 없어 잘라내야 하며,
  그만큼 화면이 좁아집니다. (2번 영상이 이 때문에 상하단을 잘라냈습니다)
- 파일당 **5MB 이하**로 압축해 주세요.
- 소리 없이 자동 재생됩니다. (브라우저 정책상 음소거 필수)
- `.mp4` 옆에 같은 이름의 `.jpg`를 함께 넣으면 영상 로딩 전에 그 사진이 먼저 보입니다.

### 안전 구역 (중요)

화면 폭에 따라 PC는 위아래가, 모바일은 좌우가 잘립니다.
**손과 떡은 화면 정중앙(가로 55% 안)에** 두고 가장자리에는 배경만 오게 촬영하세요.
자막·로고는 넣지 마세요 — 가장자리는 잘리고 중앙은 문구와 겹칩니다.

## 체험관 사진 갤러리 (여러 장 순환)

체험관 섹션의 사진은 **자동으로 넘어가는 갤러리**입니다. 사진을 늘리려면
이 폴더에 파일을 넣고 `index.html`의 `<div class="gallery">` 안에 한 줄만 추가하면 됩니다.

```html
<div class="gallery" data-interval="3200">
  <img src="assets/images/experience-01.jpg" alt="체험관 외관">
  <img src="assets/images/experience-02.jpg" alt="체험관 내부">
  <img src="assets/images/experience-03.jpg" alt="설명">   ← 이렇게 추가
</div>
```

| 항목 | 내용 |
|---|---|
| 파일명 | `experience-03.jpg`, `-04`, `-05` … 순서대로 |
| 권장 비율 | **4:3 가로형** (다른 비율이면 위아래가 잘림) |
| 권장 크기 | 1200×900px, 300KB 이하 |
| 전환 간격 | `data-interval="3200"` (밀리초) — 숫자만 바꾸면 됨 |

- 사진이 **1장이면** 인디케이터가 자동으로 숨겨집니다
- 파일명을 틀리거나 파일이 없으면 그 사진만 **자동으로 건너뜁니다** (빈 화면 안 나옴)
- 모바일에서는 좌우로 밀어서 넘길 수 있습니다

## 떡카페 사진

떡카페 섹션도 같은 갤러리입니다. 현재 `cafe-01.jpg` 1장(매장 외관 사진에서 잘라냄).
사진이 1장이라 인디케이터는 숨겨져 있고, 추가하면 자동으로 나타납니다.

| 파일명 | 권장 |
|---|---|
| `cafe-02.jpg`, `-03` … | 4:3 가로형 · 1200×900px |

카페 내부, 인절미라떼 사진이 있으면 훨씬 좋습니다.
